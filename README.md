## Run

```sh
python3 main.py            # writes entry.txt to /output
MAKEFUN_OUTPUT_DIR=out python3 main.py   # or a directory of your choice
```

`main.py` is stdlib-only and deterministic — the same bytes on every run.
It validates the line first: exactly one line, 1–200 characters, no
leading/trailing whitespace.
